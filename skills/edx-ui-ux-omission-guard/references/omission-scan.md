# 遗漏扫描

对本次改动会碰到的表面逐条判断。不适用就跳过；命中项记录组件、触发动作和当前行为的证据。

- **必须收口**：不做就会让用户已要求的交互失败，或由本次 diff 直接引入。仅在授权修改范围内修复；只读审查只报告。
- **候选询问**：真实但用户没要求的交互增强。先不改代码，留给确认清单。
- 表中处置都受上述边界约束，不因命中清单就扩大授权。修复细则按主 skill 的路由交给专项，本表只负责发现缺口。

| 类 | 看什么 | 发现后的去向 |
|---|---|---|
| 未保存离开 | 路由、返回、刷新、关层时 dirty 是否丢失且无提示 | 已授权编辑流的缺口交给编辑专项；额外离开保护先询问 |
| 失败后的输入 | 保存失败是否还留着用户输入 | 编辑专项，必须收口 |
| 关层时机 | 请求未成功就关 Drawer / modal | 编辑专项，必须收口 |
| 旧响应覆盖 | 快切 Tab、快改筛选、连点保存后数据是否过期 | 编辑专项，必须收口；只读流仅检查时序 |
| 焦点归还 | 弹层关闭后焦点是否回到触发控件；弹层内焦点是否被裁切 | 本次新增或改弹层则交给布局专项收口 |
| 键盘路径 | 新控件能否 Tab 到达、Enter/Esc 是否和现有约定一致 | 本次改热区或弹层则交给布局专项收口 |
| 热区与遮挡 | 小图标按钮是否难点、被 overlay 盖住或发生点击穿透 | 影响目标交互则交给布局专项收口 |
| 滚动锁 | 弹层打开后背景仍滚，或关闭后页面滚不动 | 本次改覆盖层则交给布局专项收口 |
| 键盘顶起 | 移动端键盘挡住正在编辑的字段，且没有滚动到可见 | 候选询问，除非用户正在修这个字段 |
| 只靠颜色 | 错误、必填只靠红色，无文字 | 编辑校验缺口交给编辑专项；其余候选询问 |
| 禁用无原因 | 按钮 disabled 但界面不说明为什么 | 候选询问 |
| 破坏性动作 | 删除、覆盖、离开丢数据没有既有确认或可撤销 | 候选询问，不私自增加确认流程 |
| 部分成功 | 多字段保存只成功一半，界面像全成功 | 接口已表达部分失败则交给编辑专项；否则候选询问，不猜契约 |
| 列表不同步 | 详情保存成功，打开它的列表仍是旧值 | 用户要求保存后刷新则交给编辑专项；否则候选询问 |
| 并发覆盖 | 两人编辑同一条，后写覆盖先写且无提示 | 候选询问 |
| 空与权限 | 无数据、无权限看起来像保存成功或白屏 | 写路径误成功交给编辑专项；读路径交给 edx-async-state-completeness |
| 长文与窄屏 | 标签、错误、按钮文字把布局撑破或被裁 | 影响目标交互则交给布局专项收口 |
| 动态插入跳动 | 错误文案或异步块出现时把焦点控件顶出视口 | 本次引入则交给布局专项收口 |
| 动效 | 新动画没有尊重 reduced-motion | 候选询问，除非本次正在加动画 |

输出分组、编号、候选数量和确认门槛统一见[主流程](../SKILL.md)的「交互建议与确认」，不在此维护第二份模板。
